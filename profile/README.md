# 同花顺 · HiThink

**同花顺官方 GitHub 组织**

浙江核新同花顺网络信息股份有限公司（深交所 300033）是一家总部位于杭州的金融信息服务与软件公司。我们为个人投资者提供行情、财经资讯和投资分析工具，也为证券公司、基金公司、银行和研究机构提供金融数据、专业投研终端与软件系统。

## 国内与国际业务

在国内，同花顺 App 和财经网站服务个人投资者，覆盖行情跟踪、资讯获取、投资分析与基金服务。面向机构，同花顺提供券商软件系统及技术服务，iFinD 金融数据终端则将市场行情、公司与行业数据、研究资料和分析工具汇集到同一工作环境。 [同花顺产品](https://download.10jqka.com.cn/) · [iFinD 金融数据终端](https://ft.10jqka.com.cn/)

在国际业务方面，同花顺在中国香港、新加坡和美国设有业务实体。香港团队面向券商、银行等机构开展金融数据和投研服务。iFinD 覆盖中国内地、香港、美国、英国等市场，为跨市场行情跟踪、公司研究和估值比较提供数据与工具。 [香港业务介绍](https://www.investhk.gov.hk/en/our-clients/royalflush-digital-intelligence-hongkong-limited/) · [iFinD 市场覆盖](https://ft.10jqka.com.cn/index.php?a=helpCenter)

## AI 与金融信息服务

同花顺将自研金融大模型 HithinkGPT 和智能体技术用于金融数据查询、市场研究与信息解读。面向开发者，**Financial-API** 提供同花顺金融数据服务的接入文档、工具与示例，支持通过 REST API、MCP、CLI 和 Python SDK 将数据用于 AI Agent、量化研究和应用开发。面向个人投资者，**问财**支持用自然语言筛选股票、查询数据和解读公告，并将这些能力用于盘中跟踪和盘后复盘。面向机构，**iFinD** 将智能检索和研究报告辅助写作融入投研流程，并通过 **iFinD MCP** 将投研数据接入机构自己的 AI 工作环境。 [问财产品介绍](https://download.10jqka.com.cn/) · [同花顺半年度报告](https://static.cninfo.com.cn/finalpage/2026-08-22/1225491733.PDF)

## About HiThink

HiThink (Tonghuashun, SZSE: 300033) is a Hangzhou-based financial information and software company. We serve individual investors through market data, financial news, and analytics, and support financial institutions with research data, the iFinD terminal, and software systems. We operate in mainland China and have a presence in Hong Kong, Singapore, and the United States.

Our financial AI products include Wencai, a natural-language research assistant, and iFinD tools that integrate financial data into institutional AI workflows. Financial-API provides documentation, tools, and examples for accessing HiThink financial data through REST API, MCP, CLI, and Python SDK for AI agents, quantitative research, and application development. This is our official GitHub organization for public developer projects, documentation, and examples.
